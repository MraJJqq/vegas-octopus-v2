# Vegas Octopus V2

An independent sci-fi multi-agent trading visualization inspired by the public [TradingAgents Dashboard](https://github.com/QuocBaoLabs/tradingagents-dashboard).

## Vision
- Cinematic dark command-center layout
- Central holographic octopus / particle-energy visualization
- Six agent status panels and a decision queue
- Market cards and signal summaries
- Display-only prototype: no order execution and no changes to Vegas Signal System rules

## Status
Initial UI prototype. Market values and agent events are illustrative placeholders until real data sources are explicitly integrated and verified.

## Run
Open `index.html` in a modern browser. No build step required.
