# 第五层：正式信号 K 线渐变轮播原则

## 页面结构
- 第五层使用全屏透明覆盖层 `#vegas-right-scroll`。
- 两个图层交替承载 K 线图，渐变切换期间交叉淡入淡出。
- 不使用纵向滚动容器，不使用多卡片列表滚动算法。
- 图层仅在有正式信号时显示；无正式信号时隐藏。

## 正式信号队列
- 正式信号队列是唯一品种来源，不在第五层重新判断或制造信号。
- 通过 `window.VegasLayer5SetAutoQueue` 接收队列。
- 新增、撤销和重复品种由队列同步处理；品种去重。
- 正式信号判断及推送规则不属于本层，不得因视觉轮播改动。

## 渐变轮播
- 当前图清晰展示 5 秒。
- 随后进行 5 秒渐变交接：当前图淡出并降低亮度，下一张图淡入并恢复正常亮度；不使用 blur。
- 双图层交替使用，避免切换空白。
- 完成交接后继续清晰展示 5 秒，循环播放。
- 页面进入后台时暂停轮播；回到前台后重新开始清晰展示阶段。

## 用户交互
- 鼠标按住或触摸按下期间暂停轮播计时。
- 所有活动指针释放后，立即从完整 10 秒周期重新开始：先清晰 5 秒，再渐变 5 秒。
- 支持图表拖动、滚轮缩放和触屏捏合缩放。
- 不因普通滚轮操作额外暂停轮播；只有按压/触摸状态暂停。

## 图表与数据
- 使用 Bitget 行情源。
- 保留 1H、4H、1D 周期切换及各品种周期记忆。
- 保留 EMA 12、36、43、144、169、576、676。
- 行情数据每 15 秒刷新；复用短期缓存。
- 每次轮播只预载下一品种，双图层各持有一个图表实例。
- 不恢复全局固定视窗、共享时间范围或自动覆盖用户当前缩放/拖动视窗的逻辑。

## 维护边界
- 不恢复旧纵向滚动控制器、滚动计时器、滚动惯性或滚动恢复机制。
- 不修改第三层行情卡片滚动逻辑。
- 不修改底部正式信号播报模块。
- 修改后必须回读 GitHub main 分支，检查脚本语法和队列/交互接口。
- 静态检查不等同于桌面浏览器或平板实机验收。
