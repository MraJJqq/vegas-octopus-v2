## 需要处理的差异

1. **滚动边界**：原版是 `overscroll-behavior:none`，目标是 `contain`。先确认页面边缘是否允许滚动链传递，再决定是否严格统一。
2. **焦点缩放/透明度**：这是原版第三层卡片的视觉焦点规则。目标是单图表面板，不能直接照搬卡片缩放，否则会改变 K 线画面尺寸；需明确记录为不适用，而不是遗漏。
3. **触屏事件边界**：目标额外限制单指触摸，并在滚轮监听使用 capture；原版没有完全相同的事件配置。需在触屏设备实测，确认不会影响图表拖拽、缩放。
4. **滚动条视觉**：目标滚动条继续隐藏；不得擅自添加可见滚动条或改变位置、尺寸。

## 不属于原版滚动核心的项目

- K 线品种队列、图表数据刷新、周期切换、图表缩放和历史视窗保存属于右侧图表业务逻辑，不纳入左侧卡片滚动算法迁移。
- 原版卡片浮动动画与阴影动画属于卡片装饰效果，不应套用到单图表面板。
- 当前原版 `market-cards.js` 未发现独立滚动 watchdog 实现；不能把 watchdog 当作已验证的原版规则。
