# 第五层渐变轮播验收清单

核对对象：
- 脚本：`assets/js/right-signal-scroll.js`
- 样式：`assets/css/right-signal-scroll.css`
- 页面入口：`index.html`

## 模式验收
- [ ] 双图层交替渲染，任何时刻只有当前图和过渡中的下一图参与显示。
- [ ] 清晰展示 5 秒。
- [ ] 渐变交接 5 秒，淡出与淡入同步。
- [ ] 每轮总计 10 秒，连续循环。
- [ ] 预加载下一品种，切换时不出现空白帧。
- [ ] 无正式信号时隐藏第五层。

## 交互验收
- [ ] 鼠标按下期间暂停计时。
- [ ] 触摸按下期间暂停计时，多指全部释放后才恢复。
- [ ] pointerup / pointercancel 均可恢复轮播。
- [ ] 恢复后立即重新开始完整 10 秒周期。
- [ ] 图表拖动、滚轮缩放、触屏捏合缩放可用。
- [ ] 普通滚轮操作不触发额外暂停。

## 数据与边界
- [ ] 正式信号队列仅通过 `VegasLayer5SetAutoQueue` 接收。
- [ ] 不改动正式信号判断及推送规则。
- [ ] 行情刷新间隔保持 15 秒。
- [ ] 保留 EMA 和 1H / 4H / 1D 周期切换。
- [ ] 不存在旧纵向滚动算法、滚动计时器或旧恢复机制。
- [ ] 不存在全局固定视窗或跨卡片共享时间范围逻辑。
- [ ] 页面进入后台暂停轮播与行情刷新，恢复前台后继续。

## 发布前检查
- [ ] 回读 GitHub main 分支最新文件。
- [ ] JavaScript 语法检查通过。
- [ ] 检查 HTML 引用、CSS 选择器和缓存版本一致。
- [ ] 桌面浏览器验证完整轮播与鼠标交互。
- [ ] 平板实测触摸、多指释放、拖动和缩放。
- [ ] 长时间运行检查是否出现计时器重复、闪烁或空白帧。

说明：静态代码检查通过不代表浏览器或平板实机验收通过。
