# 章鱼素材库

本目录用于集中整理「vegas章鱼」项目可复用的视觉素材与网页模块。

## 分类

- `3d-models/`：章鱼、机械装置及场景模型
- `animations/`：动作、抓取、粒子与过渡动画
- `effects/`：光效、能量流、全息与科幻特效
- `web-modules/`：网页组件与可复用界面模块
- `references/`：视觉参考、设计说明与来源记录

## 固定模块

- `web-modules/market-cards/index.html` 是独立的历史演示样例，保留其原有模拟行情和旧尺寸，仅用于参考，不是线上生产模板。
- 线上第三层卡片的唯一生产实现位于 `assets/js/market-cards.js`（结构与真实行情数据）和 `assets/css/app.css`（视觉与尺寸）；生产模板以用户最近确认的原始玻璃卡片规格为准。
- 不得把素材库演示页的模拟行情、旧尺寸或旧视觉规则复制回生产页面。

## 使用原则

- 优先记录素材来源、许可证和使用限制。
- 优先收录可复用、可维护的素材与模块。
- 本素材库与 Vegas 信号及交易规则保持独立，不修改其代码或规则。
- 新增实际素材前，先确认来源与许可情况。
